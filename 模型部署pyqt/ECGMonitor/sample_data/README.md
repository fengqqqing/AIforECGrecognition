# 样例数据说明

- `test.csv`：离线回放和推理接口测试使用的默认样例 ECG 数据。
- `output.csv`：历史样例输出数据，保留用于人工对照。

## Demo 固定场景

当前固定 demo 场景由 `config.py` 中的 `DEMO_REPLAY_POLICY` 定义：

- 输入文件：`sample_data/test.csv`
- 固定行号：`row=3`，即 CSV 中第 4 行
- 使用样本数：`samples=2000`
- 事件节奏：每 500 个 ECG 采样点注入一次导联和心率事件
- 导联事件：`[0, 0, 0, 0]`，保持导联连接，避免在首个 2000 点推理窗口前清空 ECG 缓冲
- 心率事件：`[72, 84, 78, 90]`
- 真实模型展示：默认使用 `use_real_model=True`，该场景当前源标签为 `0`，真实模型 smoke 输出稳定为 `0`
- 手动 mock 回放：需要只验证回放流程时，可使用相同 row/samples/event 参数并加 `--mock-label 0`

该 demo 场景只用于稳定展示部署闭环，不代表模型医学准确率。

运行过程中自动生成的数据应进入 `runs/`，不要继续放在代码根目录。
